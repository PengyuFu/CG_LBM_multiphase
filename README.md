# CG_LBM_multiphase 0.1.3

用于孔隙尺度二维、三维两相流模拟的 Windows 本地 GPU 软件。通过界面设置结构、流体、边界与停止条件，查看保存帧、三维曲面和结果；可选接入用户自己的 DeepSeek API。

本版是早期公开版本。个人学习、教学、科研及企业内部测试评估免费，具体范围见 [LICENSE.txt](LICENSE.txt)。

## 下载与启动

使用前请完整阅读并同意 [LICENSE.txt](LICENSE.txt) 及其纳入的第三方条款；不同意时请停止安装和使用。

1. 在本仓库的 Releases 页面下载完整的 `CG_LBM_multiphase_Release_0.1.3.zip` 及 `SHA256SUMS.txt`。
2. 核对 ZIP 的 SHA256，再解压到可写的本地目录。PowerShell 示例：

   ```powershell
   Get-FileHash .\CG_LBM_multiphase_Release_0.1.3.zip -Algorithm SHA256
   ```

3. 保持 `CG_LBM_multiphase.exe` 与 `_internal` 目录在一起，双击 EXE 启动。请下载完整 ZIP；GitHub 自动生成的 Source code 压缩包仅含本仓库公开资料。
4. 首次使用建议选择一个内置算例，检查设置与停止条件后进行短程试算。

运行包自带 Python 及相关计算依赖，无需安装 MATLAB 或 Python。三维显示需要系统可用的 Microsoft Edge WebView2 环境。

## 当前运行范围

| 项目 | 当前范围 |
| --- | --- |
| 系统 | Windows 11 x64；当前仅在该系统完成本机检查 |
| 显卡 | 已实测 NVIDIA RTX 4060 Laptop；私有 GPU 内核仅包含 sm_89 |
| 驱动 | 需要能运行随包 CUDA 12 依赖的 NVIDIA 驱动；最低驱动版本尚未系统验证 |
| 计算 | GPU 求解；普通模型等密度，无 CPU 求解入口 |
| 精度 | 二维普通项目单精度；三维可选单/双精度；验证模板按自身配置 |
| 联网 | 常规设置和 GPU 计算在本机进行；启用 AI 时连接 DeepSeek |

其他显卡型号、GPU 架构、系统和驱动组合的可用性尚未得到确认。本包未进行发布者数字签名，SHA256 用于核对所下载文件的完整性。

## 主要功能

- 二维、三维孔隙结构导入，物性与单位设置，B/R 两相初始条件。
- 二维四边独立边界；三维 x 方向周期、两端定压或左速度/右 OBC，y/z 成对周期或固壁。
- 二维普通 B 相牛顿/CY、R 相牛顿；三维两相牛顿、截断幂律或 CY；专用验证模板有各自适用条件。
- 固定步数、PV、持续运行、时间或稳态等停止方式；暂停、继续、停止并保存。
- 三维旋转、平移、缩放、剖切、相突出及局部/全域取景；查看保存帧并导出图像、统计和场数据。
- 使用自己的 API Key 选择启用 AI 操作助手；也可直接通过界面操作。

详细步骤见 [使用说明](user_docs/使用说明.md)，科学边界见 [验证算例说明](user_docs/验证算例说明.md)，限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。

## 数据与 AI

本地配置、工作草稿、操作及对话记录默认位于 `%LOCALAPPDATA%\CG_LBM_multiphase\0.1.3`；计算结果默认在其 `results` 子目录，也可另选保存位置。

启用 AI 后，消息、项目参数与状态摘要、工具协议及操作返回会发送到 DeepSeek。API 费用由使用者承担。软件不自动向开发者上传日志或科研数据；提交问题与诊断由使用者主动完成。详见 [隐私与AI数据说明](user_docs/隐私与AI数据说明.md)。

## GPU 临时目录与 Windows 启动提示

程序会为本次进程设置 GPU 临时目录和编译缓存，不修改系统 TEMP/TMP。默认临时目录含中文时，优先使用该目录可用的 ASCII 短路径；没有可用短路径或目录不可写时，会请您选择一个当前用户可写的英文目录，路径可以含空格。选择仅保存为本软件的 runtime_settings.json，后续启动复用。命令行启动可通过当前进程的 CG_LBM_RUNTIME_DIR 指定该目录。

本版 EXE 和自有原生模块未签名。网络下载后，Windows 可能显示“未知发布者”或 SmartScreen“无法识别的应用”；企业应用控制策略或 Smart App Control 可能直接阻止运行。部分设备在其现有策略下无法使用本版。请通过官方 Release 获取并核对 SHA256；哈希只核对与公布文件的一致性，不独立认证发布者身份，也不保证系统放行。关闭 Windows 防护不属于本软件的安装步骤。

## 输出数据

MAT/CSV/VTI 保存所选物理场、坐标、单位、时间和固体掩膜。二维恢复为原图行列，三维为 (y,x,z)；固体场值为 NaN。首末帧和历史结果按实际保存，完整求解器内部状态不作为公开输出。停止后的结果文件用于分析和回看，本版没有断点续算入口。
