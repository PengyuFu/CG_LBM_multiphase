# CG_LBM_multiphase 0.1.3 使用说明

## 启动与许可

解压完整运行包，保持 EXE 与 _internal 目录在一起，双击 CG_LBM_multiphase.exe。无需软件账户、激活码、设备绑定或到期验证。许可范围见包根目录 LICENSE.txt；个人学习、教学、科研及企业内部测试评估免费。

本版实测 Windows 11 x64 / NVIDIA RTX 4060 Laptop，私有 GPU 内核覆盖 sm_89。需要兼容随包 CUDA 12 运行库的驱动及系统可用的 WebView2；其他硬件、系统及最低驱动版本尚未系统验证。

## 第一次计算

1. 新建时先选择二维或三维，再载入对应内置算例，或导入自己的孔隙结构。
2. 检查结构尺寸、固体编码、每格尺寸、B/R 两相物性、初始分布、边界、输出与停止条件。
3. 普通项目使用界面标明的物理单位；验证模板使用自身格子单位。B 为注入相、R 为驻留相，接触角从 B 相一侧测量。
4. 执行检查并启动。运行中可暂停、继续、停止并保存；暂停期间也需先结束运行再改物性。
5. 打开已保存结果，选择场和保存帧；三维可旋转、平移、缩放、剖切，选择 B/R 相及局部或全域取景。

“检查通过”表示输入与设备检查通过；“完成”表示命中停止条件。研究结果的适用性应结合模型、网格、边界和验证另行判断。

## 输入、输出和保存

- 图像结构支持 PNG/JPG/BMP/TIFF；MAT/NPY 可读取二维或三维数值矩阵，三维 TIFF 以整栈体数据读取。具体变量、编码与维度在导入预览中确认。
- 普通项目与专用验证算例使用不同参数约定，请以当前界面字段及单位为准。
- “输出设置”选择场变量、MAT/CSV/VTI；可导出统计 CSV 和图像，扩展绘图可生成 PNG/SVG/PDF。
- 二维数组按行、列；三维数组按 (y,x,z)。显示曲面与近壁闭合仅用于可视化，不替代原始场测量。
- 暂停可继续当前运行；停止、结束或关闭后，当前版本没有从历史结果恢复续算的入口。
- 设置、草稿和本地操作记录默认保存在 %LOCALAPPDATA%\CG_LBM_multiphase\0.1.3。结果默认在其 results 子目录，也可通过设置另选。项目另存位置由使用者选择。

## AI 助手

未配置 AI 时，可正常使用界面和 GPU 计算。启用 AI 需自行填写 DeepSeek API Key，选择模型并测试连接；服务商费用由使用者承担。

关闭“允许执行操作”时只解答问题。允许操作后，助手可按明确指令修改参数和调用软件功能；显示的实际操作结果为准。停止 AI 回复与停止 GPU 计算是两个按钮，需按实际需要选择。

对话与项目摘要会发送到 AI 服务商，本机还保存操作和会话记录。请先阅读“隐私与AI数据说明.md”，避免在消息或项目文字中填写无权对外发送的信息。

## 更新与保留数据

先停止计算、等待保存并正常退出，再解压其他完整版本；保留需要的项目和结果。各版本使用各自标明的数据目录，跨版本数据格式和续算能力以相应说明为准。

本版保存与打开使用0.1.3项目标识；其他内部版本的项目文件不在本版导入范围。

## GPU 临时目录与首次启动

本程序只为自身进程设置 TEMP/TMP 和 GPU 编译缓存。默认临时目录含中文且没有可用 ASCII 短路径，或目录不可写时，会打开目录选择窗口。请选择自己可写的英文目录，路径可含空格；选择保存在本版数据目录的 runtime_settings.json。取消选择会结束本次启动。命令行启动可在当前进程环境中指定 CG_LBM_RUNTIME_DIR，不需要更改系统环境。

本版未做发布者数字签名。下载后可能出现“未知发布者”或 SmartScreen 提示；企业策略、Smart App Control 可能直接禁止运行。请先确认官方发布来源和 SHA256；部分受管设备无法使用本版，请向设备管理员确认其软件部署政策。关闭系统防护不属于安装步骤。

场数据保存为所选物理量及坐标、单位、时间和固体掩膜，二维按原图行列，三维按 (y,x,z)。首帧和末帧自动保留；完整求解器内部状态不对外导出，内部快照参数不受支持。


本版包含的微软.NET兼容程序集适用随包Microsoft .NET Library条款；安装和运行前请阅读并同意LICENSE.txt第六条及根THIRD_PARTY_NOTICES.txt所载完整条款。
命令行使用--no-browser时，可预期的临时路径错误以退出码2结束；重定向标准错误可取得简短说明，本程序数据目录的startup_error.log保留不含本机路径与堆栈的摘要。桌面入口使用本程序错误提示或目录选择窗口。

图片导入的格式与资源边界：支持静态PNG（.png）、JPEG（.jpg/.jpeg）、BMP（.bmp）以及多页TIFF（.tif/.tiff），以文件实际内容核验类型；不支持GIF、JPEG2000、MPO或动画PNG，修改后缀不能转换格式。图片文件最大64 MB，每页各边8–2048格，全部页合计≤100万格、最多2048页。多页TIFF的尺寸和颜色模式须一致；当页数及其他各边均达到三维矩阵条件时，可选择全部页作为体数据。请对畸形或来源不明的结构先检查内容与结果。


PNG透明灰度：1位、2位、4位、8位和16位灰度PNG的透明色键与显式Alpha统一按白色背景处理，再按所选编码判定固体。1/2/4/8位PNG按0–255灰度判定，16位灰度保留0–65535，透明样本取对应位深白值；其余不透明数值不降位。单页和多页TIFF共用灰度转换，方向操作仍按转置后上下翻转执行。


彩色及带Alpha图片先按白底合成为8位RGB，再按(2126R+7152G+722B)/10000计算亮度。中性灰g转换后精确保持g，非整数亮度保留小数，按所选固体编码执行小于等于、大于或指定值比较。16位及浮点灰度保留原始数值范围。AVIF不在本版支持的输入/输出范围，运行包不提供其后端。


数值矩阵的固体编码按文件中实际存储的值执行：浮点16/32位输入在比较前无损提升，避免阈值被舍入回原数组精度；64位整数保留全部整数位。阈值和指定值中的整数保留完整精度，非整数参数按64位浮点数解释；指定值为严格相等，不使用近似容差。例如float32存储的0.1实际为0.10000000149011612，与输入参数0.1并不相等。导入预览中的整数极值完整显示；导入接口对整数矩阵的minimum/maximum使用十进制文本，避免浏览器或JSON接收端舍入。转置后上下翻转的顺序保持。
