# CG_LBM_multiphase 0.1.3 版本说明

0.1.3完善第三方运行组件的分发文件集与通知，修正组件来源索引、Windows文件版本信息和操作手册标题。二维、三维计算公式、物理参数和已支持的GPU架构保持。

软件功能与使用条件见使用说明和LICENSE.txt；第三方原文及通知见THIRD_PARTY_NOTICES.txt和_internal/third_party_licenses。使用前须阅读并同意相应条件。

当前实测范围为Windows 11 x64 / RTX4060 Laptop，私有GPU内核为sm_89。程序未做发布者数字签名。科学适用范围、已知失败或待验证案例以及其他限制见验证算例说明与KNOWN_ISSUES.md。

代码保护边界：自有计算模块以原生二进制形式提供，前端采用混淆处理。启动引导、前端以及CPU/GPU机器代码仍可被分析；这些措施提高分析成本，不承诺无法逆向。使用权限以LICENSE.txt及适用第三方条款为准。

本次发行资料修订补齐FreeType和liblzf的完整版权及许可通知，并修正结果页面的输出说明。软件版本保持0.1.3；准确包身份以构建标识和SHA256校验值区分。

本次依赖安全修订将 MAT/HDF5 原生组件更新为 HDF5 2.2.0，并重新构建 h5py 3.16.0；修正对应 Windows 文件偏移类型声明。该修订包含官方 CVE-2025-9274 修复，普通 MAT 与 v7.3 MAT 的导入能力继续提供。相关第三方版本、修改说明及许可原文见 THIRD_PARTY_NOTICES.txt。软件版本仍为 0.1.3。

本次图片导入安全修订同步更新图片运行组件至Pillow13.0.0，包括所需的冻结Python解码模块和原生组件；修复畸形TIFF结构产生不确定结果等上游安全问题。图片仅接受实际内容与后缀一致的静态PNG/JPEG/BMP或多页TIFF，拒绝改名的GIF、JPEG2000、MPO和动画PNG。图片限64 MB；各边8–2048格、全部页合计不超过100万格、最多2048页；多页TIFF的尺寸和颜色模式需一致。MAT和计算核心保持原有范围。本次同时补强VC运行库组装校验和第三方用户条款；软件版本仍为0.1.3。

修正1位多页TIFF按全部页导入时的灰度缩放，使黑白结构的默认阈值与单页导入一致；多页彩色与透明图片也采用与单页相同的灰度及白色背景处理。


修正灰度PNG透明色键被忽略的问题，覆盖1位、2位、4位、8位、16位输入；单页与多页读取共用灰度转换，保留高位深数值。移除未用于产品输入或输出的AVIF冻结插件及原生后端，准确随包组件和许可见第三方目录。软件版本保持0.1.3。


修正彩色、透明和调色板图片灰度换算在整数阈值及指定值比较时的误判。使用足够宽的整数承载BT.709权重和，再除以10000；中性灰与白色端点精确保持，非整数亮度保留小数，16位和浮点灰度不降位。软件版本仍为0.1.3。


修正MAT/NPY数值矩阵因类型隐式转换产生的固体误判：浮点16/32位数值无损提升后比较，64位整数按精确整数边界分类。界面完整传递整数阈值与指定值，整数极值以十进制文本表达，避免大整数舍入。五种编码的含义、坐标方向和数值范围保持；软件版本仍为0.1.3。
