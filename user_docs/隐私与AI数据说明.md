许可方及公开联系邮箱：Pengyu Fu，fpy19941225@163.com。

## 本机保存

软件在当前 Windows 用户的 %LOCALAPPDATA%\CG_LBM_multiphase\0.1.3 下保存设置、AI 配置、自动工作草稿、本地会话与操作记录、启动错误摘要等。结果默认在 results 子目录，使用者可以另选目录或另存项目。

test_sessions 目录下的 JSONL 本地记录可能包括：用户消息、助手答复、工具名称/参数/返回、项目参数变化、按钮和运行状态、反馈与文件操作相关事件。记录有字段过滤和密钥脱敏，但消息、项目名称、结果摘要及文字中仍可能含研究信息或个人路径。

这些记录供本地复盘和问题定位，软件不自动提交给开发者。当前版本不自动清理上述记录。需要备份或删除时，请先正常退出，保留所需项目/结果，再处理相应本地文件。

## API Key

使用者自行提供 DeepSeek API Key。配置保存时使用 Windows 当前用户的 DPAPI 加密，软件运行时按连接服务所需解密使用；配置文件不以明文保存密钥。本机同一用户权限下的程序与操作系统安全仍会影响凭据保密。

密钥作为请求认证信息发送给 DeepSeek。不要在聊天、问题附件、截图或项目名称里填写密钥，也不要公开 AI 配置文件。

## 启用 AI 后发送什么

AI 请求连接 https://api.deepseek.com。消息、相关对话上下文、当前项目参数与状态摘要、公开操作说明、工具协议及操作返回会随相应请求发送；测试连接会验证密钥并请求可用模型列表。

常规模型上下文剔除原始几何数组与完整流场，字段数据处理在本机进行。使用者在文字、脚本或工具交互中主动包含的信息仍可能进入请求；请确认有权向服务商发送这些内容。服务商的数据处理和费用依其实际条款，软件不作零留存或不训练的保证。

未配置或未启用 AI 时，可以通过界面设置和运行本地计算。停止 AI 回复不会自动停止已开始的 GPU 任务。

## 诊断与反馈

“预览并导出诊断”先显示白名单摘要，再由使用者决定是否保存及提交。摘要用于记录软件版本/构建、系统和 GPU 环境、运行状态与错误类别，不包含 API Key、完整对话、原始结构和完整流场。

导出诊断与完整 JSONL 日志内容不同。软件没有向开发者自动上传日志、对话、API Key 或科研数据的功能；通过 Issues、邮箱等提交附件需由使用者主动完成。提交前检查并移除无权披露的文字、路径和研究信息。

## GPU 运行目录

启动器可能保存 runtime_settings.json，其中只记录使用者选择的 GPU 临时目录路径。该目录保存本程序的启动路径链接、临时文件和编译后的 GPU 缓存，目录位置由使用者的进程环境或启动选择确定，不改变系统 TEMP/TMP。需要清理时先正常退出全部本程序进程；保留所需项目和结果。此目录不用于存放 API Key。
