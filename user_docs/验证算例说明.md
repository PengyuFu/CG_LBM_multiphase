# 验证算例与结果使用说明 · 0.1.3

案例库包含理想化示例、文献对照及仍待进一步核验的工况。运行前查看算例的参数、单位、参考类型、警告和停止方式；普通 SI 演示与专用格子单位验证不可混用。

## 模型范围

二维普通项目 B 相牛顿/CY、R 相牛顿；专用幂律及宾汉泊肃叶模板有独立条件。三维采用等密度牛顿、截断幂律及 CY，暂不支持三维宾汉、任意六面开放、CPU 求解、反应/传质、空间分区润湿或断点续算。

二维接触角、两相泊肃叶及毛细自吸模板按各自定义判停；三维原算例保留自身停止预算，可能有上限或无上限。命中预算的 limited、数值保护中止和失败应按实际状态解释。

## 已检查内容与限度

现有短程数值一致性证据用于比较相同核心在保护与打包前后的计算结果；计算核心未变时可依准确身份复用。界面、启动、控制、保存重开和显示检查用于核对软件流程。

这些证据不能代替具体工况的物理验证、网格收敛、长期稳定性或性能评估。部分粗网格幂律、芯环流及历史毛细自吸工况尚未达到科学验收要求，原结论与算例警告继续保留。

“检查通过”仅表示该项检查通过；“完成”仅表示命中所设停止条件。验证图可能是保存步的静态快照，重新打开才更新；结果需结合真实保存步与参考条件判断。

## 显示与测量

三维显示使用原始固体掩码 0.5 等值面与 phi=0 两相界面。近壁相场延拓、封闭曲面和剖切仅用于解释占据空间，物理测量仍读取原始数值场。显示层不对求解结构进行平滑。

将结果用于论文、设计或定量判断前，请核对物理假设、单位、参数来源、半格壁面位置、分辨率、Mach 数与参考依据。不要通过降低阈值把数值保护中止或误差超限解释为成功。
